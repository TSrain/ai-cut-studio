# Profile:brand-energy

用户 2026-10-12 已取消首尾帧最低墨量、最低材质种类、默认弹簧次数、固定语义节拍上限及计时/重试自动降质。密度与运动参数只描述本期设计，不作为默认必达额度；实际表达以批准方案和真实播放验收为准。60 分钟只作预算提示，不冻结范围、不自动判质量失败。

品牌发布、活动预告、口播插片、社媒竖版短片。特征是**大字 + 强色块 + 品牌资产在场 + 快节奏**,
在信息流里 0.5 秒内建立识别。它对"看清"的要求最高——观众在滑动,不会倒回去看。

## 参数

| 项 | 值 |
|---|---|
| `density.target` | 7–8 / 10 |
| 占屏率(非底色像素) | **55%–80%**。大字本身就占面积,别再堆小元素 |
| 空间层次 | 按表达需要设计，不设最低层数或材质种类 |
| 材质信号 | 可选手段，按构图与表达需要使用，不计最低种类 |
| 焦点 | 1 主 + 最多 1 次级(本 profile 比别的少一个,靠焦点唯一取速度) |
| 语义节拍 | 随口播与理解负荷设计，不设固定数量额度 |

## 配色自由度

- **品牌色优先**:用户/品牌给定的色直接作为 `palette.dominant`,不许"为了好看"改色相。
- 一个主色 + 最多两个辅助色;**强调面积 25%–35%**——本 profile 的强调经常是整块底色,这是允许的。
- 允许高饱和大色块,但彩度上限 0.19:再高在 H.264 4:2:0 下会糊成一坨(`docs/color.md` §7)。
- 允许辉光和扫光做能量感,条件是主字对比度仍达标。
- 品牌色与功能色分开:图表系列色仍取 `theme.series*`,不拿品牌色循环上色。

## 排版偏好

- kit 首选 `impact`(得意黑 + Archivo);品牌规范要求现代无衬线时用 `modern`。
- 主字 `hero` 级,占宽 75%–90%,竖版必须过 320px 缩略图测试。
- 一句话最多强调 1 处(换色或再放大一档),强调两处就等于没强调。
- 三个主要语义层级;正文不小于 `body`(44),下 320px 字幕安全区绝不放信息。
- Archivo 的 `wdth` 宽度轴是本 profile 的主要排版工具:压到 75 做窄粗标题,拉到 112 做横幅字。不许 `scaleX` 拉字。

## 材质

色块要有表面:线性或径向受光、边缘一道亮描边、落一层软投影就够了,不需要玻璃和 3D。
品牌 logo 允许直接使用真实资产(`docs/visual-first.md` 的素材政策),摆在画面里要有厚度或投影,不要贴平。
背景给一层结构:大尺度几何、斜切色带、网格或噪点——纯色底在这个 profile 里读作"没做"。

## 运动性格

- 快:入场 8–14 帧,转场 14–20 帧,整片方向一致地推进。
- 弹簧为可选表达手段，不设次数或必用额度；实际播放复核焦点与读数。
- 背景允许持续运动(色带流动、扫光循环),但文字入场后必须有 ≥1 秒/10 字的可读停留。
- 转场偏爱整屏推移、色块擦除、遮罩切换;不用旋转入场和每元素异向飞入(那是廉价模板感)。

## 什么时候不该用它

- **多步骤解释、流程图、概念对比**:快节奏 + 大字放不下解释性内容,选 `visual-max` 或 `data-cinematic`。
- **数据读数镜**:大面积强调色会压掉图表,选 `data-cinematic`。
- **纪录片、人物、文化类叙事**:高能量与内容气质相反,选 `editorial-luxe`。
- **没有任何品牌资产也没有强色可用**:本 profile 的识别度靠品牌色和 logo,两样都没有就退化成"大字贴纸",改选 `visual-max`。
- 时长超过 20 秒的单镜:这个节奏撑不住,拆镜或换 profile。
