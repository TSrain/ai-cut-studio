# keynote-calm · 发布会大屏

用户 2026-10-12 已取消首尾帧最低墨量、最低材质种类、默认弹簧次数、固定语义节拍上限及计时/重试自动降质。密度与运动参数只描述本期设计，不作为默认必达额度；实际表达以批准方案和真实播放验收为准。60 分钟只作预算提示，不冻结范围、不自动判质量失败。

> 口播 preset 从 baseline v2(2026-08-15)起的默认 profile。
> 用户原话:「口播就要设计的和乔布斯的 ppt 一样,简单直接高级」「元素太多」
> 「画框占比太大留白过少」「动画过于着急」。

## 它是什么

一屏只讲一件事。字很大,字重不重,周围全是空。动的东西极少,而且慢。

它对标的是发布会大屏,不是信息图,也不是幻灯片模板。区别在于:

| | 信息图 / visual-max | keynote-calm |
|---|---|---|
| 一屏承载 | 一个完整论证 | 一句话 |
| 元素种类 | 6–9 种 | **≤3 种** |
| 主文字字号(1080 宽) | 44–68 | **80–110** |
| 动作 | 逐元素编排 | 只有"光"在走,元素基本不位移 |
| 一拍 | 0.3–0.5s | **0.9s(`BEAT`)** |
| 缓动 | `ENTER` | **`CALM`** |
| 墨量 | 仅记录 | 不设下限 |

## 留白与可读性

不设首尾帧墨量、材质种类或明度层数下限；真实合成与连续播放检查焦点和可读性。

## 六条执行守则

1. **一屏一件事。** 说不完就拆成两镜,不要在同一屏挤两件。
2. **元素 ≤3 种。** 题目、内容、一个标记。第四种出现时先问删哪个。
3. **不许有自证性标签。** 「关键概念 · KEY CONCEPT」「对照 · CONTRAST」「三件事 · CHECKLIST」——
   这些是在向观众解释这一镜是什么,而他看一眼就知道。**眉题槽位一律不给兜底文案。**
4. **画框不许比内容大。** 底板、色块、卡片的面积加起来不超过画面的 1/4。
   要承托就用一根线、一块小色板,不要一整面墙。
5. **不许飞进来。** 元素第 0 帧就在场(压暗即可),动的是亮度不是位置;
   位移最多 10px。会飞的画面读作动画演示,不会飞的读作有人在讲话。
6. **末段至少 1/3 完全静止。** 口播还在说,画面已经安静下来——这是插片和演示的分界。

## 字体

`minimal` kit:中文霞鹜新晰黑、西文 Inter,**字重上限 500**。

新晰黑只有 400 一档,所以全系统开了 `font-synthesis: none`——请求 700 时渲真实的 400,
而不是被浏览器横向拉胖伪造出一个粗体(笔锋会糊,而且画面上不报错,只是看着廉价)。
西文压到 500 是为了和它齐平:一行字里西文真粗、中文假细,就是"中文看着虚"的来源。

## 怎么用

合同里写 `"profile": "keynote-calm"`,或给 `frame-audit.mjs` / `check-density.sh`
传 `--profile keynote-calm`。口播 preset 镜(`docs/presets/`)默认就是它。

**不适用**:图表镜、数据密集镜、需要同屏对比多项的镜。那些走 `data-cinematic` 或 `visual-max`——
把一张有六个系列的图表塞进这个 profile,结果是字大到放不下,不是高级。
