# 风格卡:极简科技(苹果发布会 / 科技媒体)

**适用**:产品发布、AI/科技观点短视频、高端品牌数据展示。

## 参数

- **底色**:深色 `surface.dark`;整片只用深色,不切换明暗
- **色彩**:`scenePalette(250, 'dark', {accentChroma: 0.13})`——低彩度冷蓝;中性层承担全部层次,一个画面最多 1 种彩色,强调面积压到 5% 以下
- **字体**:`heroQuiet` 路线——展示字用 `FONT.text`(Inter + 思源黑体)weight 300,靠「大 + 细 + 松」拿高级感,不靠粗;正文 `body`。**不用得意黑**(它的态度太外放,与本风格相反)
- **字号**:偏大一档——能用 h1 就不用 h2;主数字用 hero 级
- **动画速度**:偏慢。入场 18–24 帧,转场 24–30 帧;运动"准而稳",到位即静止
- **缓动**:只用 ENTER/EXIT/MOVE 标准曲线;**全程禁用弹跳**
- **镜头**:缓慢的推近(scale 1→1.04 级别)制造呼吸感;无快速切换
- **光影**:可用极淡的径向渐变提亮画面中心(不超过 4% 亮度差);无投影、无描边

## 禁止

- 弹跳、抖动、快速连切
- 多彩配色、渐变文字、发光描边
- 装饰性粒子、科技感网格背景(俗)
