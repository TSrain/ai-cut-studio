# 风格卡:强对比短视频(口播 B-roll)

**适用**:竖版口播视频配图、知识类短视频、观点强调动画。

## 参数

- **底色**:深色 `surface.dark`;可整片纯色,允许场与场之间底色微变(同为深色系)
- **色彩**:`scenePalette(hue, 'dark')` 高对比——`ink` 白字为主,单一 `accent` 标关键词;彩度可到 0.18 但不要更高(压缩会糊)
- **字体**:展示字用 `textStyle('hero')`(得意黑 + Archivo,weight 800、字距 -0.03em);关键词可再放大一档或换强调色,一句话最多强调 1 处。**斜切首字记得补 `paddingLeft: '0.14em'`**
- **字号**:大。竖版正文不小于 body(44),主信息 h1 起步;必须过缩略图测试
- **节奏**:快。每 1–2 秒一个视觉事件;入场 8–12 帧;**没有静止超过 2 秒的画面**,但每条信息仍要给足阅读时间
- **缓动**:ENTER 为主;**允许一个焦点元素用弹簧强调**(全片同一时刻仍只许一个)
- **镜头**:允许快速推近/整屏滑动转场;方向要连贯(全片统一向左或向上推进)
- **安全区**:严格遵守 `theme.safeVertical`,字幕区(下 320px)绝不放信息

## 禁止

- 三种以上颜色同屏
- 全屏飞入、旋转文字、彩虹渐变
- 为了节奏牺牲可读性(读不完 = 白做)
