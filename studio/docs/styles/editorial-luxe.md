# Profile:editorial-luxe

用户 2026-10-12 已取消首尾帧最低墨量、最低材质种类、默认弹簧次数、固定语义节拍上限及计时/重试自动降质。密度与运动参数只描述本期设计，不作为默认必达额度；实际表达以批准方案和真实播放验收为准。60 分钟只作预算提示，不冻结范围、不自动判质量失败。

杂志跨页、纪录片片头、高端品牌宣传片的那种画面:大图、宽栏、衬线、精确的留白、缓慢的镜头。
**它不是"克制版 visual-max"**——它的密度来自图像与版面结构,而不是元素数量;要求同样高,只是钱花在别处。

## 参数

| 项 | 值 |
|---|---|
| `density.target` | 6–7 / 10 |
| 占屏率(非底色像素) | **40%–65%**。低于 40% 是空,不是高级;高于 65% 就失去编辑版面的呼吸 |
| 空间层次 | 按表达需要设计，不设最低层数或材质种类 |
| 材质信号 | 可选手段，按构图与表达需要使用，不计最低种类 |
| 焦点 | 1 主 + 最多 2 次级锚点;次级通常是眉题和图注 |
| 语义节拍 | 随口播与理解负荷设计，不设固定数量额度 |

**留白是被安排的,不是剩下的。** 判断法:说得出这块空白在做什么(让图透气、给标题让位、承载视线路径),
就是版面;说不出,就是没做完——去补图、补图注、补栏线、补元数据轨。

## 配色自由度

- 一个主色 + 最多两个辅助色;**强调面积 10%–20%**,靠面积小、位置准取胜。
- 底色允许偏离中性:纸白、暖灰、深墨绿、酒红。避开"米白 + 陶土色"这个 AI 默认组合(`visual-language.md` §6)。
- 允许从主视觉图里吸色定 palette——有大图时这是首选做法,不要拿通用色相盖上去。
- 允许极淡的辉光和暗角(用来做胶片感),不允许彩虹渐变和霓虹描边。
- 颜色在合同 `palette` 里声明一次。

## 排版偏好

- kit 首选 `editorial`(Noto Serif SC + Instrument Serif);叙事、人物、温度类内容用 `human`(霞鹜文楷 + Inter)。
- 展示尺寸给衬线,正文给同 kit 的无衬线或文楷;`caption` 级元数据是本 profile 的签名元素(眉题、图注、日期、栏目名)。
- 三个主要语义层级 + 微型元数据豁免——本 profile 的微型元数据会比别的 profile 多,这是版面的一部分。
- 行内西文抬 6%(`latinInline`),中文正文行高 ≥1.6,窄栏主动改断行位置而不是改标点。
- 严禁伪粗体:Instrument Serif 和思源宋体是单字重,不许调 `fontWeight`。

## 材质

摄影/插画是主要材质来源,画面里应该有**一张真的图**。没有图可用时,用大尺度的排版本身充当图像
(超大引号、跨页数字、被裁切的标题)。补充材质:纸纹、细颗粒、暗角、极软的投影、发丝级栏线。
不要做玻璃、金属、粒子和 3D——那是 `visual-max` 和 `data-cinematic` 的语言。

## 运动性格

- 慢而稳:入场 18–24 帧,转场 24–32 帧,推镜 scale 1→1.04 级别。
- 弹簧为可选表达手段，不设次数或必用额度；实际播放复核焦点与读数。
- Ken Burns 是主力手法:推向的焦点必须走 `docs/locate-protocol.md` 拿坐标,不许目测。
- 背景允许极低强度运动(颗粒流动、光缓慢移动);文字停留期间画面接近静止但不完全冻结。
- 转场偏爱遮罩擦除、图像交叠、栏线引导,不用硬切加特效。

## 什么时候不该用它

- **口播短视频的 3–15 秒插片**:慢节奏在竖版信息流里等于没看见,选 `brand-energy`。
- **多指标数据镜**:衬线 + 大留白撑不住密集读数,选 `data-cinematic`。
- **产品发布、促销、活动预告**:需要的是冲击不是气质,选 `brand-energy` 或 `visual-max`。
- **手里一张可用图都没有,也不打算生成**:本 profile 的密度靠图像撑,没有图就会做成空版面,改选 `visual-max`。
- 它不是"稳妥选项"。选它必须是因为内容要编辑感,不是因为想少冒险。
