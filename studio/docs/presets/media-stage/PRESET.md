# 标题素材展示 v1

用途：一张截图/参考板或一段视频＋一个简短标题，用于口播中解释素材。用户指定的SC-0032人物定妆参考是构图来源；本模板不自动添加脸部框选、多图轮播或额外说明。

控制台：素材演示 → 标题素材展示。默认大瑞 Keaton 姓名墙（无角落署名），顶部动画背景可换纯色、渐变、名字墙或透明。

图片/视频导入会清空另一个槽位并更新宽高时长。图片默认完整展示；可选固定比例并切换铺满裁切。视频默认静音、播完停末帧，亦可循环；起点不能超过视频时长。标题默认得意黑、逐字上浮，可选宋体/粗黑体与整体揭示/字距收拢。文字可通过通用字体面板单独调字号、颜色和位置。

支持横竖画布，素材依据原比例适配标题下方的展示区。标题最多36字，推荐4–14字。不改用户原工程；真实参考示例单独保存为media-stage-demo-20261010。
