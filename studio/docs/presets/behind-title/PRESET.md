# 人物身后大字

添加模板时自动使用本机 Apple Vision 准备当前片段的人物前景，背景视频 → 文字 → 人物前景按原源帧同步合成。文字为可编辑原生实例，快速缩放入场、收缩淡出，最后一帧透明。

内容页可调整文案、字体、字号比例、归一化位置、颜色及进出场时间；文字页保留字体、字重、字号和坐标编辑。默认 3 秒，使用主视频实际工程画幅。

要求 macOS 本机分割可用，底片为工程同帧率 CFR、方形像素。失败时显示错误并可重新准备，未完成不能导出。剪辑区间或底片改变后重新准备；轨道锁定、删除或切换工程时不会把迟到结果应用到别处。人物身后层必须完整底片导出；仅导出透明文字不包含遮挡效果。分割准确度受头发、运动和背景影响，不代表用户已采用。

入场和退场分别选择：默认缩放、向上、向下、向左、向右、淡入/淡出。滑入选项标明起点和方向；滑走选项标明退场方向。旧实例未保存效果字段时保持原缩放。选择效果不改变抠像缓存，不需重新准备人物前景；时长继续独立调整。
