# recede · 退让镜

> 文字大小和出入场可调；未带新字段的旧实例保留原效果。

```yaml
version: 2
name: 退让镜
role: 全片情绪最低点——核心结论/情绪转折/CTA 这些句子不加东西,减东西
duration_seconds: [2, 5]
colors: 全部来自皮肤(baseline.json 当前版);底=带色相压暗的 bg + 中心微光 + 网格点
typography: >
  整块同一字族。基准档 94px、主焦点 ×1.6(150px);无 hero 时整句都按主焦点档走,
  并优先缩字保住单行(缩到 78% 仍不够才折行),缩字下限 60px(主焦点 96px)
layout: >
  视觉居中(比几何中心上移 56px);左右安全 72px、折行预算 936×0.92;
  行距 1 行 1.20 / 2 行 1.14 / 3 行 1.06;字块左缘一条 88×2px 锚点细线,墨色随 level 递减
motion:
  - {phase: enter, seconds: 0.5, action: 上浮 24px + 淡入(首帧 25% 可见,无黑帧)+ 锚点线 55%→100%, easing: ENTER}
  - {phase: hold, seconds: elastic, action: 亮度呼吸 ±3% 周期 4s,别无动作}
slots:
  line: 整屏唯一一块字,自动折行最多 3 行(约 14–18 个中文字);要指定断行写 \n
  hero: 可选,line 里要放大的那段子串(必须逐字出现);省略 = 整句一个字号(等同 v1)
variants: {level: 1–4 亮度档,4 是全片最暗一帧}
```

## 用法

合同镜条目只写:

```json
{"id": "shot-003", "preset": {"id": "recede", "version": 2},
 "presetProps": {"durationSeconds": 3, "variant": {"level": 4},
   "slots": {"line": "知识，是人类最慢的生产资料", "hero": "最慢"}}}
```

排出来是两行:「知识，是人类」(94px,62% 墨)/「**最慢**的生产资料」(最慢 150px 满墨)。
不传 `hero` 就是 v1 的样子:一句话一个字号、满墨色、能一行就一行。

## 什么时候用 / 不用

- **用**:观众该停下来消化的那一句;上一镜信息密度很高之后;结尾收束。
- **不用**:句子里有两个以上信息点(那不是退让,是没设计);需要图/数据佐证的句子。
- **hero 怎么挑**:挑这句话里**观众只记得住一个词**的那个词(判断/转折/数值),不是主语。
  挑不出来就别传——通体一个字号也是合法的退让,硬造主焦点反而把句子切碎。

## 踩过的坑(SC-0025 一批攒下的)

- **一行字是一个表达,不是零件拼的**:「10 年 = $2,000」上一版让数字、汉字、货币符各走一个字族,一眼看出是拼贴。整块交给 hero 样式的字族栈自己 fallback,不许手动拆 span。
  (v2 的 hero 槽只改**字号与墨色**,不换字族,同一条约束继续成立。)
- **暗 ≠ 黑纱盖脸**:用 `alpha('#000', dim)` 压暗会把底色色相杀死,黑得死;必须在 OKLCH 里带色相压(baseline 的 RecedeStage 已内置,别绕过它)。
- **同批多镜退让要逐级递减亮度**(level 3→4),四镜一个亮度会读成复制粘贴。
  v2 补一条:**两镜时间上紧挨着时,只靠 level 拉不开**——尽量让它们的折行形状也不同
  (一镜单行、一镜 hero 独占一行),否则观众会觉得是同一张卡闪了两次。
- frame-audit 会因低墨量报警——这是正当例外,`--min-ink 4`,review.md 引 preset.json 即可,不用每次写理由。
- **折行算法是双源手抄**(`tools/lib/preset.mjs` 与 `templates/remotion-base/src/style/fit.ts`):
  改任何一边的 `WRAP_SAFETY` / `SHRINK_TOLERANCE` / `EMPHASIS_RATIO_DEFAULT` / 避头标点表,
  必须两边同改,否则展开器预告的版式和真渲出来的不是同一个。`tools/tests/preset.test.mjs` 会拦。


## 编辑器文字控制（2026-10-14）

在右侧「文字」或「内容」中，拖选整句话的一段，点击「放大选中文字」或「恢复普通」。可标记多处，重复词可只选其中一次；预览中的高亮表示放大。支持全部普通/全部放大，改字时未改动前后缀的标记跟随移动，新插入的字保持普通。

普通字号范围 8–400 px，放大倍数 1–3。长句按安全宽度等比适配；已有整体缩放仍生效。新建模板默认不预选重点，出场/退场均为无。可选淡入淡出、上移、下移、缩放，对应时长 0.05–2 秒，短片段窗口会自动收缩。

新字段都在 slots：`emphasisRanges: [{start,end}]` 使用 UTF-16 位置（含起点、不含终点）；`[]` 明确全部普通，缺省沿用 hero。`fontSize`/`emphasisRatio` 控制字号。`enterFx`/`exitFx` 为 none/fade/rise/fall/zoom，`enterSeconds`/`exitSeconds` 为秒。缺省动画字段保留旧入场与整镜溶出；显式 exitFx 只影响文字与锚点线，背景保持原样。实例的剪辑局部时间同时用于预览和导出。
