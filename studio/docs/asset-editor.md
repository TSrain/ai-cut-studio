# 资产编辑页

编辑页已接入现有 26 个 Remotion 模板（含从上一条视频提炼的章节导航）和章节进度条，共 27 项。模板库支持搜索、真实缩略图和悬停动画预览。复用本项目控制台后端、字体、组件和渲染队列；没有迁移 Overlay Studio 的模板样式，也没有加入研究报告第四部分的制作规则。

## 打开

```sh
node tools/build-asset-browser.mjs --serve
```

控制台左侧点「时间轴编辑」，进入独立页面 `/editor`。在「做片子」里选择任一模板，也可点「进入时间轴编辑」带入当前文字、位置和皮肤参数，保留控制台当前设置。普通模板复用原品牌和音效包装；数字、胶囊仍走专用可编辑叠层组件。

## 常用操作

1. 添加资产。每点一次就是一个独立动画实例，同模板可重复使用。
2. 点击画面里的数字、单位、说明、标签或章节标题，在右侧调整。也可用「编辑小项」下拉选中。字体、字号、字重、字距、行高、宽度、对齐、颜色、透明度和位置会直接反映到预览。
3. 时间轴拖色块移动动画，拖两端改起止；标尺、空白轨道和播放头均可拖动定位，缩放与横向滚动后位置仍按时间轴计算。顶部边线可调整时间轴高度。左右箭头逐帧，Shift 加箭头跳 10 帧，空格播放/暂停。图层顺序独立于开始时间。
4. 保存、另存、打开；撤销和重做支持快捷键 Cmd/Ctrl+Z、Shift+Cmd/Ctrl+Z。小项可恢复默认，也可将样式同步到本片同类动画。
5. 设置底片时填项目内相对路径，例如 `projects/项目名/input.mp4`。会读取视频的实际画幅、帧率和时长；有底片的完整导出保留底片声音。PNG、已烤平 MP4 内部的文字无法作为小项编辑。

字重和字体能否显示对应笔画，仍受字体文件实际包含的字重约束。字体选项来自本地字体库。

## 选择与快捷键

重叠的动画可以按住 Alt 点击画布循环选层，也可从本片列表或时间轴选中。选中动画后按 Backspace 或 Delete 删除，Cmd/Ctrl+D 复制，Cmd/Ctrl+S 保存，Esc 取消选择或关闭弹窗。文字输入框里的退格仍然只删除文字。点击时间轴或画布会结束输入框焦点，避免快捷键失效。Home / End 定位首尾。

普通模板可以修改各自真实的内容槽位、样式变体、整体字体、配色、位置与缩放。数字、胶囊、章节进度还支持原有小项编辑。普通模板现已为真实文字节点提供小项选择，支持字体、字号、字重、文字颜色、透明度与位置偏移；数组按当前内容展开。图表的自动数值与刻度可调样式，内容由数据生成。素材槽位需要填写已有本地素材路径。HyperFrames 片段和原子组件不在这组 Remotion 模板计数中。

## 智能章节进度

「字幕与章节」里粘贴 SRT，点「智能总结章节」。沿用本机已登录的 Codex，启动只读总结任务，不增加另一套模型服务。总结按语义分组，每章保留字幕来源编号；后台再从原字幕计算实际时间，不让模型编时间。

生成后可以改标题、改章节开始帧、拆分、合并。自动总结必须包含每条字幕且顺序一致；手动调整可使用没有字幕编号的章节。条段长度按章节时长分配，填充按整片当前帧推进。新建资产中的「待导入字幕」仅是占位示例，并不代表已经总结了视频。

若本机 Codex 未登录、网络失败或任务超时，可下载总结任务，在当前 Codex 会话处理，再粘贴返回的章节 JSON。字幕本身必须有时间码；只有普通文本时不能据此推测真实时间。

组件支持 `hiddenIntervals: [{startFrame,endFrame}]` 隐藏区间，隐藏时全片时钟继续推进。首版界面暂不提供任意隐藏区间控件，可在文档参数中设置。

## 导出

| 选项 | 结果 |
|---|---|
| 仅此模板图层 | 只输出所选实例，无其他模板和主轨声音；透明层用带 Alpha 的 MOV，整镜模板用 MP4 |
| 该时段全部图层 | 按模块或镜头块的起止区间输出合成 MP4，含底片、声音和同时可见的所有图层 |
| 全部导出 | 一个含底片的视频 MP4；没有底片时使用预览的背景 |
| 整条动画层 | 一个覆盖全片时间轴的 MOV，不带底片；透明资产保留透明，整镜资产的背景也保留 |
| 逐动画导出 | 每个动画实例一个文件。两个同模板实例就是两个文件；每个从自己的起点开始，不保留前导空白 |

时间轴每个动画行旁有导出图标，属性面板提供「导出此模块」。点击后先选择范围，再点击「开始导出」。口播镜头是底片效果，只提供合成时段；普通模板同时提供单层和合成。单层导出保留模板引用的素材内容（已合成视频本身无法自动拆回图层）。单段结果校验后自动保存到 `~/Desktop/产物/<脚本编号或项目ID>/片段/`，名称区分单层与合成，不覆盖旧文件。

导出中可点击「取消导出」：排队任务移出队列，运行任务停止自己的渲染进程；已完成文件保留，未完成输出不发布。关闭弹窗不会取消，顶部「正在导出 · 查看进度」可重新打开。

导出文档只保留与区间相交的图层，选中单层只保留该实例。底片区间使用原生视频路径；严格符合全画布、不透明、无额外变换条件的已渲染视频复用画面并合入对应主轨音频；其他情况仍走完整渲染。已有源码指纹缓存用于复用编译结果。

透明叠层用 ProRes 4444 MOV，保留整幅画布和原位置；整镜背景资产用 MP4。数字的单位、说明与主体一起导出。全片进度条是一个全时长实例。附带清单记录原片起止帧、起止秒、画幅、帧率、资产版本和导出路径。

导出会冻结文档与组件源码副本，经过现有 `render-queue`（并发 2），并核对输出画幅、时长和透明通道。多批任务在后台依次进入同一条队列。页面显示每项状态，失败可只重试失败项。导出过程中继续编辑，不会改变已进入队列的版本。

项目和历史：`workspace/editor-projects/<项目ID>/`。导出：该目录下 `exports/<任务ID>/`。页面提供下载链接，文件不会覆盖同名历史产物。

## 当前边界

- 三类资产已完整接入；其余 Remotion 模板、HyperFrames 和历史任意源码工程尚未自动转换，继续使用原工作流。
- 侧边数字默认透明、无纸屑；原整镜数字仍保留原样和纸屑变体。编辑器资产版本是新增编辑适配版本，不把旧 preset 的 verified 评级自动升级。
- 品牌标记、独立音效控制、画面自由拖拽、全套字幕编辑器迁移不在首版内；位置可通过右侧参数即时修改。
- 导出文件、文档和源码快照持久保存；服务重启后不恢复运行中的任务状态。失败时可重新发起导出，历史文件仍在磁盘。
- 智能总结需要本机 Codex 可用；初次加载本地字体可能稍慢。

### 短视频素材导出缓存

标题素材展示（media-stage）的短时 SDR、方形像素、恒定帧率视频，在 contain / auto 布局且源分辨率显著超过输出所需分辨率时，worker 自动生成目标画幅缓存。保留原片、编辑文档、帧序和音轨；缓存使用 Lanczos 缩放和 H.264 无损编码，仅用于内部渲染。放大倍数纳入尺寸计算；裁切、HDR、旋转、VFR、长视频等不满足条件时继续使用原路径。缓存按原视频内容和尺寸区分，位于 public/editor-render-cache，不进入桌面产物或 Git。performance.json 记录 mediaMs、preparedMedia、mediaCacheHits；诊断可传 --original-media 对照。

### 共享口播转写

控制台字幕通过 editor-transcribe-worker.py 调用自媒体工作流的统一转写入口，先用原媒体音轨身份查共享缓存；命中时不抽取上传音频、不上传、不调用飞书 ASR。仅未命中时提取音频并识别。旧控制台 recognized.json 可登记到共享缓存，已有共享记录优先保留。首次身份校验会本地读取音轨（不是语音识别），后续复用来源指纹。缓存位于自媒体工作流 workspace/transcript-cache；改字幕风格、调整镜头或新建项目不应再次识别。原始时间码转写、字幕精简稿和排版分别保存。
