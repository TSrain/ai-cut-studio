# 编辑台交付检查（2026-09-07）

## 当前结论

本机常用流程已能走通：选择文件 → 自动画幅 → 添加动画 → 调整样式 → 保存重开 → 完整导出或逐动画导出。
这可以作为本机试用版；尚不能把它称为无需协助的正式交付版。下面把已完成、必须补齐和未验证项目分开，不以模板数量代替完成度。

## 本轮已落实

| 入口 | 现在怎么操作 | 自动处理 |
| --- | --- | --- |
| 底片 | 点击「选择底片 / 更换底片」，打开系统文件选择器 | 识别真实尺寸、旋转方向、帧率、时长；匹配横竖比例，默认 1080 规格输出；预览固定 30 帧，导出另选帧率 |
| 尺寸镶嵌的视频 | 内容页直接选择视频 | 自动填写素材宽高、时长；修复视频槽错误拼接目录导致无法播放的问题 |
| 截图推近、手机截图、字形遮罩图片 | 内容页直接选择图片 | 自动填写源图宽高；可选图片支持移除 |
| 字幕与章节 | 点击「选择字幕文件」 | 读取 SRT 文本，保留粘贴入口 |
| 原控制台上传与做片子页 | 已有系统文件选择器，保留 | 用户无需填写本地读取路径 |

导入文件复制到项目管理的素材目录，不依赖原文件所在位置。文件名冲突不会覆盖旧素材。上传显示进度；无效文件、空文件和超限文件给出错误，失败临时文件会清理。当前编辑页视频 / 图片单文件上限为 4 GB，字幕为 10 MB。

后续素材默认沿用当前画布比例；横屏素材放进竖屏底片时，不会擅自把整片改为横屏。
底片导入和旧文档载入均换算为 30 帧预览时间轴，已有动画保持秒位置。新底片过短会阻止替换，不会悄悄裁掉已有动画。章节内容是否仍适合新底片，需要重新核对。

## 实际验收

- 64 项回归测试通过；编辑器、模板 TypeScript 检查通过。
- 普通横屏、竖屏及带 90° 旋转信息的视频均核对；不只依据文件名或存储宽高判断。
- 浏览器按钮触发文件选择事件；底片、图片、视频、字幕均实际导入。
- 导入图片自动回填 768 × 432；保存重开后图片、视频与画幅仍在，播放器可继续播放。
- 完整视频实际导出并查看画面；使用两个动画实际得到两个文件：一个 MP4、一个透明 MOV。
- 透明 MOV 检查结果：1080 × 1920，`yuva444p12le`；时长匹配动画自身区间。
- 修复参数面板中数值滑杆重复标签、文件选择控件被旧表单双栏挤压的问题。

本轮证据在 `workspace/editor-round5/`。测试使用短素材，不能据此推断长片、所有编码或任意模板参数已经完全可靠。

## 正式交付前需要补齐

| 优先级 | 项目 | 目前问题 / 证据 | 完成标准 |
| --- | --- | --- | --- |
| P0 | 自动草稿与恢复 | 编辑页仍依赖手动保存和离页提示，没有持久化未保存草稿 | 意外关闭、刷新后能恢复最近编辑；不能覆盖用户正式保存版本 |
| P0 | 导出任务恢复 | 后端任务索引在内存中；虽有磁盘清单，服务重启后查询会找不到任务 | 重启后能看到历史结果；中断任务可重新执行，已完成文件不丢失 |
| P0 | 长片稳定性 | 本轮使用 2 秒短素材；未完成长底片、多素材持续编辑与大文件验收 | 用一条真实长口播走完导入、拖动、保存、导出；检查音画同步、内存、磁盘与失败提示 |
| P1 | 模板完整参数验收 | 26 个模板已有横竖关键帧，但未遍历所有变体、长文案、极端字号与字体 | 逐模板登记验证范围，测试多段文字和极端设置，修复溢出 / 重叠；范围外不声称已适配 |
| P1 | 模板库预览一致性 | 部分预览仍为旧布局、旧配色和旧画幅 | 重新生成预览；缩略图与进入编辑后的默认状态一致 |
| P1 | 新用户操作闭环 | 部分失败仍暴露后端字段或较技术化的提示，部分控件缺少就地反馈 | 选择、替换、移除、重置、取消、失败重试均有清晰状态；错误提示能告诉用户下一步怎么做 |
| P1 | 素材管理 | 导入副本能保证引用稳定，但未做重复素材识别、项目打包与无引用素材清理 | 项目可打包搬迁；清理只删除无引用文件；显示占用空间 |
| P2 | 格式扩展与代理预览 | 当前没有完整的 HEVC / HDR / 可变帧率 / 超大视频兼容矩阵 | 明确支持格式；不支持时提供转码或代理方案，而不是让播放按钮失效 |

建议按「防丢失与任务恢复 → 真实长片验收 → 模板参数与预览一致性 → 素材管理」推进。先保障做完、保存住、导得出，再扩展样式与更多功能。
