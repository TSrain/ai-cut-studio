# 品味判例

`memory/taste.md` 是**流水账**——逐项目记「选了什么/改了什么/不满什么」,是原始素材。
本文件是从那些素材里提炼出的**判例**:编号、可引用、可检查。

判例格式固定四段:

- **原话/触发** —— 用户怎么说的,或哪个项目暴露的。不写这段,半年后没人知道它为什么存在。
- **结论** —— 一句话,可复用的那部分。
- **做法** —— 具体到参数或动作。
- **落点** —— **谁第一个发现它被违反了**。三档:`门禁`(脚本能量出来)/ `资产`(组件、preset、蓝图承担)/ `仅文档`(暂时只能靠读)。

> **`落点: 仅文档` 的条数就是待办清单**,那是下一批该被脚本化的东西。这个数字应当逐月下降。
> 按「修复强度分层」:规则执行错了先想能不能脚本量出来,文档措辞是最弱的一层。

`review.md` 与 `DELIVERY.md` 可以直接引编号(如「违反 Q3」),不必复述整段。

## R — 节奏

### R1. 节奏宁慢勿快;关键信息落定后必须呼吸

**原话/触发**:历史反馈全部指向「放慢 / 停留」,**从未有一次「太慢了」**。
**结论**:初版默认比直觉慢一档。末段静止不是浪费,是给观众读的时间。
**做法**:末段留 ~1s 静止定格(退让镜 1.4s);品牌字标 hold ≥1s;批量动效收尾留 0.5s 静止;一拍 0.9 秒(`BEAT`)。排时间线时**预先给 hold 留帧预算**,不要等超时了再砍。
**落点**:`资产`(蓝图的相位表 / preset 的时间线常量)+ `仅文档`

### R2. 首帧不淡入

**原话/触发**:多次返工——插片首帧淡入 = 观众看到黑帧。
**结论**:插片首帧画面必须已经在场;需要"运动已经开始"就用负延迟头启。
**做法**:`moveStart: 0`,或让入场动画的起始帧为负值,使第 0 帧落在动画中段。
**落点**:`门禁`(可量:抽首帧算墨量,接近 0 即违反 —— 目前 `frame-audit` 只在给了首帧时按 10% 下限判,尚未强制取首帧)

### R3. 一种动画手法全片只当一次主角

**原话/触发**:重复镜头、重复 tagline 一律删。
**结论**:飞入/堆叠/翻页,每种在一支片里只能当一次主角;第二次出现就降级成配角或换手法。
**做法**:分镜阶段先列手法清单逐镜对应,发现重复当场换。
**落点**:`仅文档`

### R4. 相邻退让镜要拉开**形状**,不是只拉亮度

**原话/触发**:`broll-SC-0025-preset-v2` —— r02 与 r05 时间上紧挨,都排成「首行降档 + hero 独占次行」,`level` 亮度差(1 vs 3)只解决了一半,形状仍近。
**结论**:形状差比亮度差管用。
**做法**:紧邻的两张退让镜,有意让一张走单行、另一张走 hero 独占行。
**落点**:`资产`(已写进 `docs/presets/recede/PRESET.md` 的坑位)

## Q — 质感与构图

### Q1. 字体和配色不许用默认值

**原话/触发**:「你给我的这个设计,字体和配色都太 low 了,但我不是设计师,我不知道如何告诉你方法论,你自己调研融入」(`2026-07-31-wideseek-信息源`,整屏一个绛红 chip 网格 + `system-ui`)。
**结论**:三条归因——`system-ui` 是全世界的默认值,自带「没做选择」的气味;配色没有明度结构就像贴纸不像空间;手写 hex 会让两个「看着一样深」的色差十几个感知明度点。
**做法**:`textStyle(kit, role)` 取字,`scenePalette()` 取色,合同里 `typography.kit` 与 `palette` 显式声明。禁 `system-ui`,禁中文静默回退,禁手写 hex。
**落点**:`门禁`(`tools/lint-shot.mjs` 查字体/配色令牌该用没用)

### Q2. 降低彩度 ≠ 变中性

**原话/触发**:`wideseek-redo` 第一遍把胶囊做成「品牌色的三档明度」(彩度 .045–.11),渲帧一看还是整屏一个色相。
**结论**:主体必须是**真中性**(彩度 ≤.035),品牌色才配叫强调色。
**做法**:骨架走明度阶梯;一个主色 + 最多两个辅助色;强调面积 10%–35%。
**落点**:`门禁`(`frame-audit` 报离板颜色与强调色面积)

### Q3. 浅色画面需要一个深色锚点

**原话/触发**:同上返工。最深的东西只是文字时整张图会发飘。
**结论**:让一部分主体做成「反白文字的深色块」,画面立刻有骨架。
**做法**:浅底上「越来越浅」只有一格余量(实测最浅档对底色 1.01 对比度 = 不存在),层级要走**明度 + 形态**双重梯度:实心 / 描边 / 软填。
**落点**:`门禁`(`frame-audit` 的明度层数)

### Q4. 构图不许堆一侧

**原话/触发**:用户反馈「信息不要堆在一边」。
**结论**:对角或上下平衡;大字不压线条边界。
**做法**:`frame-audit` 报质心偏压时先判体裁——列点/时间轴版式天然左对齐,那是特征不是失误;**居中或自由版式**出现同样偏压才是问题。
**落点**:`门禁`(`frame-audit` 质心偏压,需人工判体裁)

### Q5. 屏幕字做大做考究,卡片文案弱化为肌理

**原话/触发**:`shot3` 返工。
**结论**:同一画面里「要被读的」和「表示有一堆东西的」必须拉开两个量级。
**做法**:顶部标注 76px/800;卡片标题降到 20px、`ink.muted`、opacity 0.7。一旦卡片标题可读,观众就会去读,焦点就散了。
**落点**:`资产`(`SkeletonCard` 的坑位注释)+ 见 T1

### Q6. 收尾不要「实心色块」

**原话/触发**:`shot3` —— 收尾的实心蓝圆角块「丑」。
**结论**:表达「仅存一点点」用小尺寸高亮**描边**卡 + drop-shadow 微光,不用实心块。
**做法**:描边 + 微光,干净不廉价。
**落点**:`仅文档`

### Q7. 手绘感要克制

**原话/触发**:用户反馈抖动过大。
**结论**:抖动 ≤±0.2 笔宽——直中带手感,不是发抖。
**做法**:`AnnotationMark` 的 `seed` 控制笔迹;同屏多个批注换 seed。
**落点**:`资产`(`AnnotationMark`)

### Q8. 一屏一句话(口播)

**原话/触发**:「像发布会大屏」。
**结论**:元素 ≤3;删掉自证性标签;画框 ≤1÷4;动亮度不动位置。
**做法**:见 `docs/styles/` 与 preset 皮肤。
**落点**:`门禁`(密度上限尚未脚本化)+ `资产`

## T — 排版与文字

### T1. 要被读的文字有最低有效字高

**原话/触发**:项目自己的口号是「缩到 320px 宽仍可读」,但长期**没有任何脚本在执行**。
**结论**:字幕 ≥5% 帧高,辅助文字 ≥3%。**按最终像素量算,不按 `fontSize` 算**(有缩放变换时两者不等)。
**做法**:字号阶梯里最小的 role 换算到目标画布后不得低于 3%;镜头 tsx 里不许出现裸 `fontSize` 数字字面量绕过 `textStyle()`。
**落点**:`门禁`(`tools/lint-shot.mjs`,2026-08-20 加)

### T2. 长句在窄竖版拆两行,不改字

**原话/触发**:`shot2` / `shot2redo`。
**结论**:窄竖列放大字号靠**主动折行**(`pre-line`),不靠改文案、也不靠缩字号。
**做法**:「小标签(灰)+ 大重点句」两行,各贴中线向内对齐。
**落点**:`资产`(`ContrastColumns` 的 `payoff` 支持 `\n` 主动折行)

### T3. 一句话内部的主次,比一句话一个字号值钱

**原话/触发**:`recede@v2`。
**结论**:hero 子串 ×1.6 + 其余降墨,是一张纯文字卡从「一行大字」变成「有版式」的最小改动。
**做法**:只动字号与墨色、**不换字族**——换字族就掉进「一行字拼贴」的坑。
**落点**:`资产`(`recede@v2`)

### T4. 折行算法两侧必须共用一份口径

**原话/触发**:`recede@v2` —— 展开器(JS)与组件(TS)各自估宽,展开期预告「排成 2 行」,渲出来是 1 行。
**结论**:保险余量写进算法内部(`WRAP_SAFETY 0.92`),不许各调用点各乘一遍。这类漂移**看不见也测不出**,常量对拍测试是唯一防线。
**做法**:无 hero 时优先缩字保单行(`SHRINK_TOLERANCE 0.78`);有 hero 时先满字号折行;hero 整段不许被拆开;定行数后二分目标宽度做均衡,避免孤字尾行。
**落点**:`门禁`(常量对拍测试)

### T5. 换字体后必须重标宽度估算系数

**原话/触发**:`wideseek-redo`。
**结论**:Inter 比 Helvetica 宽,且预设自带 +0.03em 字距,不重标则流式版面容器宽度全部偏小。
**做法**:换字族 → 重跑宽度标定 → 重渲 `TypeSpecimen` 核对。
**落点**:`仅文档`

### T6. 字幕层排版四条硬规则

**原话/触发**:字幕层管线返工。
**结论**:错位随行宽收敛;只有「铺垫 → 结论」才错位;结论行升档位;文案要提炼。
**做法**:见 `tools/lib/caption-spec.mjs`(渲染器/linter/预览共用一份常数)。
**落点**:`门禁`(`tools/lint-caption-script.mjs`)

## S — 声音

完整方法论在 `docs/sound-design.md`(判例正文 + 卡点方法),这里只列编号与落点,不重复正文。

| 编号 | 一句话 | 落点 |
|---|---|---|
| **S1** | 按**片种**选音不按事件选;禁音色不禁动作。`ui/` 必须逐个试听,不许整目录放行 | `资产`(CATALOG.json 的 `verdict` 字段) |
| **S2** | 连发音效要双样本交替 + 音量阶梯递减 + 间隔加速,三件一起做才像一串 | `仅文档` |
| **S3** | 声音在画面锁定之后做;时间线一动,SFX **全表重钉**不做局部微调 | `仅文档` |
| **S4** | 拟音优先于装饰音,音频裁到与动作严格等长 | `仅文档` |
| **S5** | 钉帧一律相对 shot 起点,不用绝对帧 | `门禁`(可量) |
| **S6** | `volume` 是**乘法系数不是目标音量**;轻音素材要预归一化 | `资产`(CATALOG.json 的 `quiet` 字段) |

卡点另有一条硬判据:**渲后必须回测,切点误差 ≤3 帧**

跟着一个不存在的拍子剪,比不卡点更糟。
**落点**:`门禁`

## C — 文案与信息

### C1. 演示数字不许伪装成真实结论

**结论**:演示可以用虚构数字,但合同要写 `facts.mode: "illustrative"`,画面上也要标。
**做法**:图表镜的角标全程可见。
**落点**:`门禁`(`tools/validate-contract.mjs`)

### C2. 图标是盖章不是主角

**原话/触发**:`LottieClip` 的坑位。
**结论**:图标**永远晚于文字入场**(delay ≥8)。
**落点**:`资产`(`LottieClip` / `SemanticIcon`)

### C3. 硬币是视觉、文字是信息,两者不重复

**原话/触发**:Shot9 v1 —— 币面写「5角」+ 旁边又写「不到5毛」= 冗余。
**结论**:币面只放表意符号(¥ / ★),别写具体信息。
**落点**:`资产`(`MetalCoin`)

## P — 流程

### P1. 交付前必须自己渲帧逐一检查

**结论**:「能运行」不等于完成;没看过画面就不许交付。首检永远不能交给用户。
**做法**:先数字后眼睛——`frame-audit` 能算的别用眼睛判;自查帧一律 `--scale=0.4`。
**落点**:`门禁`(`frame-audit` / `check-density` / `validate-review`)

### P2. 样式类反馈改皮肤或升 preset 版本,不改当次镜头

**原话/触发**:`SC-0025-preset-v2` —— 用户只说了一句「用零三这种形式,注意排板的美观度」。
**结论**:这是样式类反馈,正确动作是**升模板版本**;判错就等于把风格资产散在一次性镜头里。
**做法**:按路由表判一次:样式 → 皮肤/preset 升版本;内容 → 改本镜。
**落点**:`仅文档`(路由表在 `.devin/skills/motion-broll/SKILL.md`)

### P3. 可参数化的产物要配自助界面

**原话/触发**:字幕改错字这类小毛病,走一轮「说给我听 → 我去找 → 我改 → 重渲」成本远大于问题本身。
**结论**:用户十秒能判断的事,给界面不要给对话。
**做法**:控制台「改字幕」区;成品视频的二次编辑见 `UPGRADE-PLAN.md` 条目 F。
**落点**:`资产`(控制台)

### P4. 抽组件才算沉淀,散文不算

**原话/触发**:17 个项目下来 `taste.md` 攒了二十几条具名手法,组件库却只有 3 个组件。
**结论**:换一个内容还能用 → 抽组件;只对这条内容成立 → 留在项目里。
**做法**:抽的时候把坑写进组件注释;**同时登记进 `docs/catalog/components.json` 的 `params` / `pitfalls`** —— dispatch 的 shortlist 从 JSON 算,只写散文表 worker 读不到。
**落点**:`门禁`(`tools/tests/component-catalog.test.mjs` 的参数表棘轮,2026-08-20 加)

### P5. 「砍简版不如全版」的返工,复用全版代码只压时间线

**原话/触发**:Shot6 —— 用户反馈「精简两拍版没有第一版好」。
**结论**:最省事的路子是拿被砍前的全版代码,只改时间线常量做等比提速,一张卡都不删。
**做法**:缩 stagger + dur,视觉母题零重写;前提是每段仍留独立顶部大标签锚定「现在在哪一步」。
**落点**:`仅文档`

### P7. 样张的关键帧要围着**取样帧**设计,不是围着一个完整动作

**原话/触发**:2026-08-20 一天里栽了两次。`PageCam` 样张首尾给 rotY 8°→−4°,
`DepthCam` 样张首尾给 yaw −18°→14° —— 两次的取样帧(第 60 帧)都正好插值到 ±2°,
**渲出来和平面运镜一模一样**,而组件本身完全正常。
第一次踩完在注释里写了「倾角低于 8° 等于没开 3D」,第二次照样栽。

**结论**:样张是**一张静帧**,它只需要在那一帧上说清这个手法是什么。
按「一个完整动作」设计关键帧,取样帧落在哪儿全凭运气。

**做法**:先定取样帧(`CatalogThumb` 是第 60 帧),再让关键帧区间在那一帧上给出**有辨识度的状态**。
需要时首尾都给同号角度(如 −22° → −10°),不要为了「动作完整」跨过 0。

**落点**:`仅文档`(可量化:静帧的 3D 参数插值结果能算,但阈值随手法而异)

### P6. 指代含糊的反馈先确认对象

**结论**:改错了整份干净回滚,不在错误版本上打补丁。
**落点**:`仅文档`
