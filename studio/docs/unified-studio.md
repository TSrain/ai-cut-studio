# 统一视觉工作室

启动：在 visualization 目录运行 `PANEL_SKIP_REAP=1 node tools/build-asset-browser.mjs --serve`，进入 http://localhost:4321/editor 。根路径也进入编辑工作区。

## 日常操作

1. 左侧选模板、素材、声音、字体或参考。单击先预览；模板卡片的 + 或中央“添加到时间轴”才加入作品。
2. 选中时间轴动画，在右侧改文字、样式和位置。修改作用于当前作品。时间轴可折叠，浏览素材时保留作品。
3. 图片先选中带图片槽的模板，再预览图片并“应用到选中模板”；公共目录外图片会复制到导入目录。视频可“设为底片”，自动匹配画幅。
4. 顶栏保存、打开、另存、导出。未保存编辑自动写入当前浏览器草稿；再次进入时选择恢复。草稿不替代正式保存。
5. “字幕导入 / 章节规划”处理 SRT 章节；左侧“字幕”和“管理”在当前窗口打开高级工具，返回时保留作品。

## 当前边界

- 本轮统一入口和操作衔接；高级字幕、组件、图标、皮肤、存储等仍复用原管理模块的内嵌视图。
- 时间轴支持动画、主轨与独立视频/图片小窗叠放；小窗可裁切、设置素材起点和持续时间。音频库仍用于试听和管理，尚无多音轨混音或完整剪辑软件的变速、转场等功能。
- 删除仅允许未被已保存作品引用的编辑器导入文件，移至 `workspace/studio-trash` 隔离区；内置及共享资产只读。隔离区 manifest 保存原路径，可由 Codex 协助恢复。
- 浏览器草稿可能受清理缓存影响，重要作品应正式保存。多个标签页并行编辑时以保存版本冲突保护为准。

## 主轨同步小窗（2026-10-08）

模板库选择“主轨同步小窗”，加入动画时间轴。它动态引用当前主轨的视频：放在第 5–6 秒，就播放主轨对应的第 5–6 秒；移动实例后引用时间随之变化。若主轨设置了源起始偏移，小窗沿用该偏移。

- 未提供视频时画面留空，仍可安排时间和修改参数；之后设置视频底片即可显示。只有音频时无需伪造或补充人物画面。
- 默认居中裁切为 1:1。右侧“原视频取景”显示原片和裁切框：拖框移动、拖四边或四角改变长宽，也可用宽高滑条或常用比例按钮。显示原片尺寸与裁切比例，不拉伸人物。整体大小与原片取景分别控制。
- 入场和退场各 9 种：全屏缩入/展开、淡入淡出、直接切换、四向滑动、缩放弹入/收起、翻转。可调过渡时长。边框粗细为 0–80 像素，0 表示无边框；颜色、圆角和阴影独立控制。
- 完整预览和导出复用同一个持续播放的主轨视频，只改变取景和显示区域，进出小窗不再挂载第二个播放器，避免其首帧缓冲暂停原声。单独导出小窗时静音。其他动画按图层顺序叠放，同层级小窗优先。
- 支持完整合成导出和带透明背景的小窗单独导出。当前仍是单个主视频，不包含多段剪辑时间映射、变速或自动人脸跟踪。

内容工作流继续保留原有 package/B-roll 文档，真实素材候选放在文档中供人工查看；控制台用于动画和可选主轨预览。本次只实现小窗模板，B-roll 自动填入控制台属于后续步骤。
