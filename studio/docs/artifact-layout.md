# 产物目录：以直接找资源为准

公开版交付目录默认是仓库根目录 `output/`，可由 `PRODUCTION_PLAN_ARTIFACT_ROOT` 覆盖，不绑定桌面位置。

统一入口 `../output/<SC-XXXX>/`，两个仓库共用同一个脚本项目。按实际文件按需建立 `封面`、`动画素材`、`视频素材`、`效果预览`、`成片`；没有资源就不建空目录。分类目录里直接放文件，不再套 v1/shots/shot-xxx 等层级。文件用中文内容名，必要时标口播时间及“透明叠层”；禁止用 draft、output 等无意义名字交付。

桌面只展示当前可用版本。封面 PNG/JPG、动画 MP4/带 Alpha 的 MOV、视频素材、成片及必要预览为用户资源。README、JSON、合同、转写、分镜表、日志、检查报告、构建依赖、可编辑工程和旧版本放仓库 workspace，或项目下隐藏的 `.制作资料/`。不在桌面根目录放文字说明；版本记录在内部维护。需要用户选的候选图可直接放封面/效果预览，不混入淘汰版本。

执行时内部工作目录与用户交付目录分开：渲染、验收和合同继续在内部目录完成，通过校验后复制当前可用资源到可见分类，核对字节完整性。已有资源更新时先将旧版保留在隐藏资料，不能静默删除。跨仓库传递统一 projectRoot 和 scriptId；最终答复链接可见资源目录。旧示例中的 workspace 是工作区，不是交付入口。

已有项目保持原引用有效，不为整理目录改合同哈希。无需飞书编号；SC 编号只用于兼容已有项目。

## 控制台导出归属（2026-10-10）

导出优先使用编辑文档中明确且唯一的内容编号；无编号或编号冲突时，保存到配置的输出目录，不要求登记飞书。内部工程、日志、清单不复制到交付目录。透明图层保留 MOV 格式。
