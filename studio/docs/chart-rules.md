# 图表正确性规则

**本文件是图表镜的准源。** 它取代原先引用的外部 `dataviz` skill —— 那个 skill 已不在
marketplace 也不在磁盘上,凡是指向它的规则等于指向空气(2026-08-10 核实并内化)。

管**正确性**,不管标注密度。密度按观看场景分三档,判据在 `docs/visual-first.md`
「图表镜:先判观看场景」——口播插片最低、独立解释镜中等、仪表盘走完整报告规范。
**三档的正确性规则完全相同,变的只是标注多少。**

## 1. 选形:按问题选,不按好看选

| 观众要回答的问题 | 用 | 不要用 |
|---|---|---|
| 随时间怎么变 | **折线**(连续性本身就是信息);面积图只在强调累积量时用 | 柱图——会被读成"五个独立类别"而不是"连续下降" |
| 几个类别谁大谁小 | **条形**(横向,标签好放) | 饼图超过 3 片;环形图 |
| 占整体多少 | 单个百分比用**大数字**;构成用**堆叠条** | 饼图(角度比长度难比) |
| 两个变量有没有关系 | **散点** | 双 Y 轴折线(见 §2) |
| 分布长什么样 | **直方图 / 密度** | 平均值一个数字 |
| 排名变化 | **斜率图**(两点)或 **bump chart**(多点) | 动画柱赛跑,除非过程本身是内容 |

选形写进 `shots[].objective` 时要说得出理由。一句话判据:**换成表格会丢失什么?** 答不出就用大数字或表格,不要为了"有图"而画图。

## 2. 坐标与比例诚信(硬门槛,不因风格豁免)

- **单轴。** 双 Y 轴任意缩放就能造出任意相关性,禁用。真要比两个量纲,改成两个上下对齐的小图(small multiples),共享 X 轴。
- **条形/柱形的数值轴必须从零起。** 长度即数值,截断长度就是骗人。
- **折线可以不从零起**(它表达变化率),但**必须有可感知的断轴符号**,或者直接改零基线。截断且不标记,比脚注冗余严重得多。
- **坐标方向不许反直觉**:时间从左到右,数值从下到上。倒置只在有明确语义时(如"排名 1 在最上")并显式标注。
- **面积映射用面积,不用半径。** 气泡图按面积缩放,按半径缩放会把 2 倍画成 4 倍。
- **单位至少完整出现一次。** 可以只在最大字号那个数字旁边出现,不必每个刻度都写。
- **示意数据必须在合同里写 `facts.mode: "illustrative"`**,不得让演示数字伪装成真实结论。

## 3. 颜色编码

- **系列色顺序固定**,同一支片子里同一个系列永远同一个颜色。跨镜也一样——观众在建立"橙色=我们"这种映射。
- **不用彩虹渐变映射数值。** 彩虹不是单调的,明度忽高忽低,读者无法排序。连续量用**单一色相的明度阶梯**;有中点的用**双极渐变**(冷—中性—暖)。
- **颜色不是唯一编码。** 色觉障碍约占男性 8%。身份靠**直接标签**承载,颜色只做次级编码;这样也天然满足"320px 缩略图能认出主焦点"。
- **强调色只给结论那一项**,其余系列压成中性灰阶。全都强调等于都不强调。
- 颜色一律从合同 `palette` 取 token,**不许在图表代码里手写 hex**(`tools/lint-shot.mjs` 会查)。

## 4. 动画图表特有的坑

- **`count_up` 的终值必须是真值**,中间插值只是过程。不许为了好看让数字冲过头再回落——那是在显示一个从未存在的数值。
- **`draw_on` 折线的绘制方向必须是时间方向**(左→右)。反向绘制会读成倒放。
- **轴和网格先于数据出现**,否则前几帧的数据点没有参照系,观众在看一堆漂浮的点。
- **图表画完必须静止足够久**读完(1 秒 / 10 字,数字按 1 秒 / 个位数计)。动完就切等于没给信息。
- **不要让 Y 轴范围随动画变化**——柱子一边长一边轴在缩,视觉上的增长量是假的。范围一开始就按终值定死。

## 5. 交付前六检

1. 这张图回答的是哪个问题?换成表格丢失了什么?
2. 数值轴起点对不对?截断了有没有标?
3. 有没有第二根 Y 轴?
4. 系列色跨镜一致吗?连续量是不是彩虹?
5. 去掉颜色还认得出谁是谁吗?
6. 终值是真值吗?静止时间够读吗?

任一条不过就改图,不许在 `review.md` 里用"风格如此"辩护——**§2 和 §4 属于技术硬门槛层**
(`docs/visual-first.md` 优先级链第 2 层),连选中的 Styleframe 也不能覆盖它们。

差值印三遍、加 `n=5` 脚注,盲评排第 3。**要砍的是标注密度,不是上面这些正确性规则。**
