## 容易混淆的选择

- 章节进度跟随全片时间；章节导航卡高亮当前章节，需要设置当前项与触发时间。
- 列点推进适合并列原因；流程推进适合顺序不可颠倒的步骤。
- 卡片列阵逐个展示内容；卡片群收束通过数量变化表达筛选，不是多系列统计图。
- 立方体导航主用途是模块介绍，因此归清单流程；其名称不代表自动章节导航。
- 玻璃胶囊打字模拟输入动作；文档自书写展示内容生成，都不是真实录屏。
- 时间轴横移展示版本史与里程碑，不是编辑器的时间轴操作。
- 关键词隧道强调量感并收束；逐词飞入动字适合需要观众读清的问题和句子。
