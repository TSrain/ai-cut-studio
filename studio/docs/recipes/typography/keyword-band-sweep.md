## 意图
划重点的价值在于**上下文还在**。把关键词单独放大占满画面是另一回事——那时观众读到的是一个孤立的词,
不知道它在哪句话里。这个手法保住整句,只让其中几个字被"记号笔"扫过。

## 动效核心
- 核心配方一行:**句子先安定,色带后扫;色带在字的下半部,跨行连续**。
- 整句用 `TextReveal` 在裁剪容器内上滑入场(运动发生在文字自己的空间里,不是全屏飞入)。
- 色带的 `delay` **必须晚于整句入场结束**。同时出现会被读成"这句话本来就有底色"。
- 深色画面上换低饱和度色:高饱和黄在深底上会发光,白字压上去读不清——这条踩过。

## 参数表
| 参数 | 典型值 | 调节手感 |
|---|---|---|
| 句子 `dur` | 18f | >24f 拖;<12f 观众注意不到它在动 |
| 静置间隔 | 句子结束后 ≥12f | 这一拍是"读句子"的时间,省掉就没有"先读句、后划重点"的先后关系 |
| 色带 `delay` | 36f | 见上。早于句子安定 = 手法失效 |
| 色带 `dur` | 15–45f,关键词越长越靠上限 | 快了像闪一下,慢了观众等得不耐烦 |
| 色带 `color` | 浅底暖黄;**深底换低饱和强调色**(如 `rgba(57,135,229,0.42)`) | 深底上用高饱和 = 白字压不住 |
| `bandHeight` / `bandY` | 贴基线偏下 | 偏上会像删除线 |

## 已知坑
- **绝不放大关键词占满画面**——那样丢掉上下文,划重点的意义就没了。
- 跨行的关键词色带必须连续,断开会读成两个词。
- 一镜只划一处。划两处等于没划。
