## 意图
章节标题的常规命运是"出现 → 消失 → 内容登场",标题和内容互不认识。
这个手法让标题**降格而不退场**:居中大字站稳一拍宣告主题,然后缩小飞到左上角,
落成这一节的栏目标签——它还在屏幕上,只是从主角变成了门牌。
观众因此获得一次免费的空间记忆:刚才那个大词就是现在左上角那个小词。

## 动效核心
- 核心配方一行:**降格是单次连续补间**(scale 与位置走同一条曲线),分两段读作两个动作。
- `Easing.inOut(cubic)` 20f:scale 1→0.3 + 位置从画面中心到左上角,**同一条曲线**。
- 居中修正量随补间同步归零(`translate(${-(1-t)*50}%, -50%)`)——不归零终点会偏一个半宽。
- 显影后**必须站稳 ≥18f 再降格**。没站稳就缩,宣告拍被吃掉,整个手法白做。
- 内容在降格进行到 12f 时就开始生长(不是等标题落位)——**这个重叠是"交接无空档"的来源**。

## 参数表
| 参数 | 典型值 | 调节手感 |
|---|---|---|
| 降格补间 | 20f `inOut(cubic)`,scale → 0.3 | <14f 读作标题被弹走;终点 >0.45 标签太大压内容 |
| 站稳拍 | 显影后 ≥18f 静置 | 省掉这拍,观众没读完标题它就跑了 |
| 生长起点 | 降格开始后 +12f | 等标题完全落位才生长会空 8f 冷场 |
| 内容错峰 | 块间 0.16t | 全部同时长出读作页面刷新,不是"生长" |
| 标题字数 | **≤3 个词** | 降格到 0.3x 后还要当可读标签,长句缩完就是一条灰线 |

## 已知坑
- 降格路径上**不许有其他元素动**——标题飞行是全屏唯一焦点;内容生长在它落点下方不抢(起点错开),但弹窗/光标类同帧入场必抢。
- 多节连用时左上角标签要**换行不叠放**:新标签落位、旧标签上移让位,否则第二节起左上角变成标签坟场。
- 上游卡是 1920×1080 语境,落点 `(150,110)`;竖版 1080×1920 要按安全区重算(本项目落点在 `(96,150)` 一带)。
- 移植自外部卡,**参数是调校起点不是实战定稿**,首次实战要用真实文案回验。
