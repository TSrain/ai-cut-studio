## 意图
"卡住"是个**否定状态**,而否定状态最难拍——画面完全不动会被读成静态图或渲染失败。
这个手法的关键是:**有动作,但动作没有结果**。光标走了、进度动了,可什么都没发生。
观众看懂的不是"它停了",是"它试过了"。

## 动效核心
- 核心配方一行:**动作要发生,结果不许发生**。
- 光标 `reach` 取 0.5–0.6:走过去一半多一点就折返。<0.5 看不出意图,>0.8 观众以为要点下去了。
- 每次试探之间**回 home 停一下**。连着走会读成随机漂移,不是犹豫。
- 进度条 `delta` 只给 1–2 个百分点。给多了读成"在推进",努力感就变成进展了。
- 两个动作**错开**:光标试探时进度不动,进度试探时光标停在 home。同时动会糊成一团。

## 参数表
| 参数 | 典型值 | 调节手感 |
|---|---|---|
| `attempts[].reach` | 0.55 / 0.6 | 犹豫的程度。两次给不同值,机械重复会露出是代码 |
| 试探次数 | 2–3 次 | 1 次看不出是"反复",4 次以上观众失去耐心 |
| 回 home 停顿 | ≥10f | 停顿才是"犹豫"的载体,不是移动 |
| `probes[].delta` | 1–2 个百分点 | 见上 |
| `pct` 基准 | 60–80 | 太低像刚开始,太高像快好了 |

## 已知坑
- 这个手法表达的是"想选选不下去",**不是"正在操作"**。真要演操作用直线到位 + 点击涟漪。
- 进度条必须有**微小动作**,完全不动会被读成静态图——那就变成渲染失败了。
- 背景的候选项要有真实文案,空框看不出在犹豫什么(样张第一版就是空框,废了)。
