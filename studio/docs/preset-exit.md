# 模板退场合同

用户 2026-10-10 要求修复分段开关特写及所有同类模板的硬切退场。

27 个注册模板统一在最后约 0.35 秒用 smoothstep 溶出，结束帧取 N-1，透明度精确归零。时间按当前模板 durationSeconds 和 fps 计算，不使用整片长度。模板总时长不增加；正文阶段保持原样，分段开关的最短版本压缩入场与交互时间，给 caption 完成及 0.25 秒静置留空间。

统一层不添加不透明底，不改变画幅、元素坐标或用户调色。编辑器的自定义背景与模板一起退场；嵌套统一层只执行一次。章节导航保留上移动作，品牌 ink 保留回收动作，由统一层接管透明度，单独引用这些组件时仍保留原生退场。分段开关增加 24px 下移、2.5% 回收，注脚小幅下移。

范围是模板库与编辑器当前注册的 preset。历史项目已经复制的独立源码与已导出的成片不会自动更新；shotcraft 参考演示不是生产模板，本次不批量改写。

验证：tools/tests/preset-exit.test.mjs 检查 27 个模板声明的最短、默认、最长时长及 24/30/60fps 下的退场曲线。真实渲染与逐帧检查放 workspace/2026-10-10-preset-exit/。面板循环片通过检查后更新 assets/previews/presets/，旧片在工作目录保存。
