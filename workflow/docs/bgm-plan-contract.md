# Package BGM 计划 v1

Package 规则唯一准源：../workflow/docs/complete-package-contract.md（本文件不重复）。

本文件定义独立 `bgm` 专项的规划方法、数据和计划轨界面。

## 方法论：先找加分点，再选音乐

目标不是只判断“能不能配”，而是判断“音乐在这里能增加什么体验或表达，用什么声音和变化实现，是否值得成本”。先通读全文、辨认不同段落的任务，再判断配乐/留白；不能把整套方法退化为“简单段轻音乐、复杂段静音”。下表是基于原调研的制作判断，不是曲风与效果的实验定律，也不要求一条片覆盖全部任务。

### 音乐可以加什么分，怎样选择

| 加分任务 | 适用情境与希望增加的体验 | 选曲和编排逻辑 | 成本与限制 |
|---|---|---|---|
| 持续观看的连续感、适度刺激 | 易懂的观点、案例、经验分享，减少主观单调感，让相邻句子/剪接听起来连贯；无需剧情转折 | 优先稳定、可循环、编排稀疏、弱旋律、柔和瞬态的器乐；按口播的语速、停顿和态度选存在感。轻微脉冲可提供前进感，平缓长音可统一氛围；不是节拍越强越有注意力。可跨相邻同类段延续，遇高负担段退出 | 低成本，可复用少量适配曲目；这是合理的体验目标，不能宣称已证明提高口播留存或理解 |
| 让观众感到过程、运动和时间 | 产品多年演进、反复尝试、等待、成长或一组有发展关系的画面；让“发生了变化”听起来有过程 | 先确定过程特征：重复尝试用反复动机，积累用逐层增加，等待用稳定脉冲/持续音，完成时可释放或结束；发展也可用音色、层次、和声变化，不必一直加速加响。所选曲目必须有可用的发展段或可编辑结构 | 中等或更高成本；只有静态循环时只能支持连续感，不得承诺时间/过程映射已经实现 |
| 帮助想象一个结构或关系 | 概念已讲清后，进入扩散、连接、从简单到复杂等可想象的例子 | 找音乐结构与概念结构的对应：重复型对应规则，新增声部对应分支/连接，织体变密对应复杂化。定义和关键推导先留人声空间，进入例子后再展开；明确音乐在哪个语义节点变化 | 通常需要定向选段/分层编排。随便循环“思考型 BGM”不能获得这种收益；无法实现时降低目标或留白，不假装已帮助理解 |
| 让故事向前，形成期待与张力 | 人物正在行动、遇阻、等待结果；观众需要感到事情仍在推进 | 先判断是好奇、悬而未决、受阻还是即将揭晓，再选稳定脉冲、未解决的乐句、克制的层次累积等候选；强度随事实进展调整。揭晓可撤乐、释放或换质感，不机械用重鼓点/预告片高潮 | 低到中成本，取决于现成曲目是否能贴合；不能给普通事实硬加危险、胜利或确定性 |
| 标示转折、章节变化，给结果留余味 | 从案例回到观点、揭示信息、转入回忆、重要一句话之后的真实停顿或无口播展示 | 把进、退、停和变化当成音乐标点。重点前撤乐可突出人声；话后可让已有动机/尾音短暂承接，再退出；选有干净入口、出口、合适尾音或可剪乐句的曲目。转折未必需要换曲，也未必需要音效 | 常是低成本亮点，优先考虑；只使用实际存在的停顿/展示区间，无真实时长就写语义建议，不虚构口播停顿或扩展工程 |
| 补充主观气氛、潜台词和观看视角 | 语言没有说尽的犹疑、陌生感、亲近感、荒诞感，或明确的主观回忆 | 先写希望观众怎样感受这件事，再选音色、空间感、稳定/不稳定感、温度和密度；可选与环境声融合的持续音，不按“悲伤=钢琴、紧张=鼓、思考=lo-fi”套标签；反差只有在含义清楚时使用 | 低到中成本。不得把配乐的态度伪装成事实，也不要在人物原声已充分动人时重复煽情 |

无口播的素材/动画展示，可以由音乐承接连续性或上述表达任务；若现场声、环境声已足够，就保留它们。节目统一听感和风格也是可接受的持续底乐收益，不要求每段另造一个故事目的。

### 怎么从任务推到曲目

1. **明确这段原本在干什么。** 是解释定义、带入案例、展示发展、等待结果，还是留一个消化空间？人声本身已有的节奏、情绪和停顿也算表达资源。
2. **提出具体加分假设。** 持续底乐可用“保持轻快但不催促的连贯听感”；定向配乐需说清“让多次失败到成功有积累和释放”等。不能只写“增加氛围”“提高注意力”“这段很长”。持续底乐相邻段可以共享同一理由，不编造逐段独立亮点。
3. **按收益选择音乐特征。** 依次考虑时间/变化结构、脉冲与密度、旋律抢耳程度、音色与瞬态、和声/情绪方向、可剪入口出口，再用曲风关键词检索。类型标签是搜索辅助，不能代替适配理由；BPM 和音量百分比也不能代替与人声的实际适配。
4. **区分铺底与编排。** 简单铺底可增加统一听感和连续性；过程/结构映射往往要求选特定乐段、重复、分层或在节点变化。必须写清额外做法和成本。高成本而收益不明确时改用较简单目标或留白；不要给普通口播默认电影级配乐工程。
5. **安排衔接与收束，再核对代价。** 按下节同时判断内容关系、音乐结构和注意力，不默认每段重启或固定两秒双淡化。不跨越应留白的区间。重点前是否撤乐、话后是否让音乐接住、是否延续同一动机，都依据内容。数字密集、概念辨析、多步推理、强烈真实情绪和直接交流可留白；不是遇到这些词就自动静音。只有“思考型”曲目标签不构成帮助思考的证据。
6. **按具体要求推荐曲目。** 推荐理由必须说明它匹配哪个任务、哪些已核实特征，以及还要如何剪辑/编排。若要从简到繁而曲目没有已核实的层次变化，不能声称匹配；未试听时只能依据官方介绍等已查信息写候选理由，并明确待听验的特征。候选来自国内外真实来源，不要求国别配额、不按名气排名、不用“好听/很火”代替适配。

### 衔接与收束：先决定关系，再挑手法

时间轴已回答在哪里；`transition` 回答怎么接、带来什么收益。包括音乐接音乐、音乐接纯人声以及片尾收束。每处给一个首选，必要时一个低成本备选，不罗列整套菜单、不重复起止范围。

先判断三种关系：内容是在继续、转向还是结束；前后音乐的乐句、节拍、和声与响度是否适合连接；变化应被观众察觉还是保持隐形。以下是制作经验的口播适配建议，不是普遍效果定律。

| 手法 | 操作与适用收益 | 条件及代价 |
|---|---|---|
| 自然收尾再起 | 借前曲合适的结束乐句收住，留纯人声后再起；给章节或结尾句号感 | 低至中；需实际找到可剪结尾，不能每段隆重终止 |
| 乐句交接／直切 | 前曲乐句末接后曲合理起句，保持推进 | 中；实听检查节拍、和声及响度，卡鼓点不等于自然；必要短交叉处理仅修接缝 |
| 尾音搭桥 | 前曲停止继续演奏，只留最后一声衰减，再接后曲；承接余味 | 中；优先原有尾音，混响不可糊字或跨已确定留白，和声不合不强叠 |
| 下一段提前铺入 | 后段音乐在前句结尾低声出现，在现有停顿或章节转换处显露再回到人声下 | 低至中；建立期待，不提前泄露反转，不挤占重点或留白，无空间则不用 |
| 同曲换层 | 利用分轨或编配版本减鼓、留氛围、加节奏；同逻辑下改变能量 | 有分轨时较低；必须核实分轨/版本，不能假设普通成品可无损拆层 |
| 停乐让人声接棒 | 借休止、断奏或音符结束撤乐，让反问、判断、转折单独成立 | 低；随机截断像故障，不机械每句强调；无合适节点则短淡出 |
| 反向尾音引入 | 后曲干净单音尾声倒放为短吸入，再接正常起音 | 中；仅明确揭示/画面展开少用，未试听不能假定存在可用尾声 |

默认选择顺序：意思与音乐作用都没变→同曲直接延续；意思讲完或需要认真听→自然收尾/撤乐交人声；确实换内容但保持推进→先乐句交接，再视适配选尾音搭桥或渐变；需要提前期待→提前铺入，明显效果只在揭示场面使用；仅能量变化→优先同曲不同层次。相邻计划块不是重起音乐的理由。平常、不可察觉的衔接可正好满足连续体验目标，不为炫技而换曲。

渐入渐出仍是有效工具，但固定前后各2秒不是默认处方。按语义、乐句及实际可用长度决定；约3秒的短段若进退已占满就应找独立短乐句或留白，不先涂满再靠淡化补救。不延长工程，不生成虚假的乐句秒点。真实时间/试听未到位时写语义策略和待听验条件，不声称音符、BPM匹配、分轨或收尾已验证。

推荐曲目须同时评估可用入口、休止、结尾、版本/分轨；官方介绍可作检索依据，具体位置与适配必须试听后确认。收益仍保留前文六类，不用转场技法取代音乐作用判断。

来源：[TAL 制作人](https://transom.org/2015/using-music-jonathan-menjivar-for-this-american-life/)、[Transom 叙事衔接](https://transom.org/2019/scoring-stories-part-2/)、[乐句交接与分轨](https://blog.native-instruments.com/phrase-mixing/)、[自然结尾](https://www.premiumbeat.com/blog/cap-your-music-tracks-for-a-smooth-ending/)、[尾音衰减](https://www.premiumbeat.com/blog/add-natural-reverb-music-tracks/)、[反向尾音](https://www.epidemicsound.com/blog/how-to-transition-between-songs-in-your-video-with-adobe/)。DJ 的音乐结构原则可借用，不把长时间混音照搬到口播。

### 成本与效果边界

音乐的收益包括听感舒适、主观连贯、适度刺激、表达和想象的支持；这些不等于已证明减少走神、提高完播率或提高理解成绩。我们的默认是：低成本连续底乐可以成立；明确的转折/余味值得少量投入；过程与结构配乐按收益决定是否投入额外编排。没有音乐也可以是完整方案。

音乐不能修补拖沓论证、重复内容、差录音。判断是否值得保留时，保持人声响度不变切换有乐/无乐，检查获得了什么、是否更难跟上语言；手机小音量尤其注意鼓点、尖锐音色、循环接缝和重复疲劳。方案阶段写“预计/希望增加”的效果，只有实际组合听过才写听验结论。实际获取与剪辑执行见 `docs/bgm-auto-execution.md`，不伪造试听。

SFX 与 BGM 分别判断。SFX silence 只是不新增短音效；BGM silence 只是该段不铺底乐。若音乐的变化已承担一次强调，音效不要再重复打点；BGM 只有计划时，不能声称已混音或自动 ducking。

### 输出必须带走这些判断

沿用现有字段，不把内容只写进 report 而从控制台消失：

- `reason`：写这段的内容情境、预计加分点及值得使用的原因。定向表达补充为什么普通静态底乐不够；silence 写收益不足或具体负担，不仅写“不需要”。
- `musicType`：简洁显示可检索的类型/功能，例如“稀疏脉冲器乐”“逐层展开的重复型器乐”，不只写“思考型”。
- `texture`：写“特征 → 对应收益”的选曲逻辑，必要的发展变化、如何实现及额外编排成本；不只列乐器名或堆形容词。持续底乐可以一句说明稳定、稀疏、可循环为什么适合本段。
- `transition`（衔接与收束）：一个简洁文本写首选处理、具体收益，必要时给低成本备选。绑定口播语义节点，说明同曲延续、收尾、撤乐、换曲或尾音承接；不只重复起止点、不默认2秒双淡化。只使用现有真实范围，不臆造乐句秒点，不跨越留白。新提案使用本字段；旧提案缺少本字段时兼容完整 `entry` + `exit`，界面合并显示但不改写原证据。显式空白/非法 transition 不回退旧字段。
- `recommendations[].reason`：具体曲目匹配本期哪类任务、依据是什么、还需何种处理/听验；禁止所有推荐复制同一句“适合口播”。来源、许可、试听状态分别记录。

一个合格计划可以是：

> 这段讲三轮试验逐步解决问题，音乐预计增加积累感。选择重复动机且能逐层展开的器乐；循环对应反复尝试，层次增加对应进展，关键结果前撤掉让人声落地。需要选段并对齐语义节点，成本高于单曲循环；如候选仅有不变循环，就只承诺连续感。前面的原理定义段保持纯人声。

这只是结构示例，不能每段套用相同故事或强制制造音乐亮点。

### 原调研与案例边界

完整依据保留在 `workspace/research/2026-10-19-口播配乐-电影与播客经验.md`。本合同已带入专项决策必需的原则，专项无需读取整段聊天或全量研究历史。以下是制作经验，不是中文口播效果试验：

- [Andy Mills / Radiolab](https://transom.org/2014/using-music-andy-mills/)：音乐可表达运动、过程与时间；人声自身也有节奏。
- [Jonathan Mitchell](https://transom.org/2014/using-music-jonathan-mitchell/)：定义先纯人声，想象河流网络时用由简到繁的重复结构；收益来自与内容对应的编排，不是“思考”标签。
- [This American Life 的制作指南](https://transom.org/2015/using-music-jonathan-menjivar-for-this-american-life/)：进退、变化与话后承接参与叙事；强烈材料也可无配乐。
- [Carter Burwell 的创作笔记](https://www.carterburwell.com/projects/NCFOM.html)：按具体观看体验选声音，避免把情绪标签机械映射为配器。

## 运行与数据

专项输入包含冻结完整语义、脚本、真实时间与保护状态；输出为 SHA 绑定的 proposal/report/result。

提案形状：

```json
{"schemaVersion":1,"branchId":"bgm","items":[],"reason":"全文审阅后的总体安排","sections":[{"id":"shot-001","requirementVersion":1,"bgmDesign":{"decision":"music","reason":"案例易懂，轻底乐提供连续感","purpose":"continuity","musicType":"轻节拍器乐","texture":"稀疏、弱旋律、柔和瞬态","transition":"沿用前段同曲保持连续，复杂推理前借自然收尾撤乐让人声落地；无合适收尾时短淡出","recommendationIds":["track-1"]}}],"recommendations":[{"id":"track-1","title":"真实曲名","artist":"真实作者","url":"https://example.com/track","reason":"基于已核实信息的适配理由","licenseStatus":"unknown","audition":"not_listened"}],"recommendationGaps":[]}
```

示例 URL 只是结构示意，生产输出必须真实检索。从作者/官方曲库页等核实具体曲名、作者及来源；未实际听过写 `not_listened`，许可未核实写 `unknown` 或 `verify_before_use`。有配乐段却没有可靠候选时写 `recommendationGaps`，不编造曲目。全部段落恰好覆盖一次，版本绑定冻结需求；留白写 `decision:silence` 和具体 reason。music 项的类型、音色、用途、衔接与收束说明与推荐引用必须完整。purpose 可为 continuity/narrative/atmosphere。`licenseStatus:verified` 必须附原始许可依据 `licenseUrl`，不等于用户已购许可。

主控加载已验证提案，写到 `productionPlan.shots[].bgmDesign` 与顶层 `bgmPlanVersion/bgmRecommendations/bgmRecommendationGaps`。`bgmDesign.requirementVersion` 绑定实际段版本，失效时提示重做，不显示过期块。保留手调、锁定和三方合并冲突。

## 控制台

在所有视觉、字幕、镜头、原片和音频轨道之后显示独立“BGM 计划”行。仅 music 段按当前 `shot.timing.ranges` 显示标记，不另估秒点；不显示 estimated/unaligned/review 定位，不给 silence 段填块。点击标记选择对应段并定位；上方当前段详情展示音乐类型、作用、衔接与收束和单独的推荐曲目区域。音效留白不隐藏 BGM，删除段落和过期版本不留下幽灵标记。它是计划轨，不生成虚假可播放音轨。

## 验证边界

检查完整覆盖、版本、URL、安全 JSON、推荐引用、范围及保存合并。计划数据测试覆盖 scope、分支证据、空白、失效、切剪跟随；执行数据另按自动执行规范验证。构建/自动测试、浏览器实际交互、真实模型产出、曲目听审与最终采用分别报告。

## 音频应用接口

执行数据与获取步骤见 `docs/bgm-auto-execution.md`。应用接口读取最新工程与全部 BGM/留白区间，记录曲目、SHA、来源、署名及所需编辑。

同曲且相邻的计划块优先合并为连续 AudioClip，不逐块重启。只在现有配乐范围内选段、淡化、自然尾声或交接，不侵占已确定的留白。短段执行既定留白备选时同步更新该段决定与理由。未实际听审时，音量可依据人声与音乐实测电平保守预设，但不能称作听感通过。

使用控制台原生独立音轨与 load/save CAS，保存前检查 revision、源片、画布、计划时间和现有音轨；不覆盖手调、锁定、删除记录或其他声音。`styleReference.allowedOverrides.bgmApplication` 保留本次来源、许可、试听状态及 `clips[].clipId/shotIds/method` 的关联，界面根据当前实际音频是否存在显示入轨状态。重复操作先识别已有应用，不重复添加或自动覆盖。

原生音频支持源选段起点、音量、静音、分割/裁剪、淡入淡出时长；`fadeInCurve/fadeOutCurve` 可选 `linear/smooth/equalPower`，旧存档默认直线。预览与 FFmpeg 导出共用包络定义，切分和局部导出不重启淡化；主动修改淡化则以当前片段为范围重新计算。时间轴包络线展示实际淡化形状。跨曲重叠使用不同音轨；等功率曲线不保证所有音乐叠加都保持主观响度，仍需听验。自然尾声来自实际曲目选段，不虚构混响或分轨效果。

入轨后回读、检查所有留白区间没有 BGM、核验实际文件解码与导出处理，再通过控制台播放和参数修改/撤销检查。发布署名放本期隐藏资料并在交付中给入口。技术检查、控制台播放、主观听审和最终采用分别记录。
