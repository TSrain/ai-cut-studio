# 自动素材与动画共轨规则

仅针对Motion Studio制作流程自动新增的视觉实例：真实素材、原生动画模板、普通媒体识别追加及Claude清单动画。没有时间重叠时尽量共用“自动素材与动画”轨道；前一项结束帧等于后一项开始帧可共轨。重叠或叠加顺序冲突时增加轨道，后续无冲突项继续复用已有自动轨道，不按素材类型分轨。

只复用本规则新建且保留自动归属的轨道。用户改名、改变序位、锁定、隐藏或加入手动片段后，该轨道不再自动复用。不根据名称推断历史轨道归属；已有实例和历史轨道不重排，参数、时间、zIndex、显隐与删除记录保持。明确替换旧实例时沿用其轨道，不触发共轨整理。

自动素材和动画仍是独立实例，能单独选择、移动或删除。字幕、主视频、镜头辅助轨和音频专用轨维持原机制。共轨只整理新视觉实例的放置，不改变口播映射、素材音频静音、动画拆合镜或最终采用状态。

后端准源：`../studio/tools/lib/automatic-visual-tracks.mjs`，由production-plan-jobs的统一追加入口调用；不调整手动拖入/复制粘贴入口。

## 主动整理已有轨道

Motion Studio 时间轴工具栏新增「整理轨道」（眼睛左侧），用户点击后按类型、时间冲突和叠加顺序合并已有可编辑轨道，支持一次撤销。该入口可以整理历史手动轨道，且只在用户主动点击时运行；日常自动追加仍遵守本文件的保护范围，不自行重排历史工程。详细规则见 `docs/track-organization.md`。
