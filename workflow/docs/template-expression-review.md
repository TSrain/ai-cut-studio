# 全文模板表现力复审（2026-10-14）

适用于新 semantic-template-v1 package/handoff/broll。动画语义分析及先行 Claude 任务交付完成后，独立重新审全文模板机会；不是只复核已经被标成 required 的动画段。用户等本窗口持续汇报，任务退出、实际结果回读及缺口汇总前不发最终回复。

## 目录与理解

输入中的 templateCatalogPath 是从当前 visualization 的全部 preset.json 生成并 SHA 绑定的能力目录；templateCatalogAuditPath 对比 MENU 的 ID/版本。先读审计；MENU 漏项或版本过期不能作为排除模板的理由，直接读取能力目录中的定义、PRESET.md 与必要组件，按 source SHA 记录本轮依据。不要只从菜单摘要、模板名或旧经验选择。未观看的模板不写已动态验收。

分别理解原生模板的表达用途、画面主体、字号/画幅适配、运动与进退场、皮肤、实际准备链路。目录里 documentation/component 路径及 SHA 供直接读取；sample/anchors 是原生能力线索，不是可直接复制的本期内容。

## 全文第二遍

按完整共享 SRT 检查每句话，再合并为合适的意义与强调区间。逐段识别概念引入、关键判断、结论、转折、个人经历强调、数字、并列、对比、步骤和素材呈现；none/保留真人不等于该段无需检查。不能因为模板不能模拟复杂机制，就放弃其中适合原生强调的短句；原生强调可承担局部重点，其余机制交 Claude，partial 写明缺口。

对有表达机会的段落比较现用模板，说明具体视觉收益和采用/不用原因。无收益的段落明确保留真人；没有固定次数、覆盖率、类型数或每句一个模板的额度。人物身后大字是概念与结论的候选之一，不是所有题材默认方案。字幕重复、白色小胶囊和轻微出现本身不代表完成画面设计；不得把“放得下文字”当表现力合格。

使用能发挥模板原生画面与动作的参数。在真实工程尺寸、人物位置、字幕、安全区下复核整体比例、层级、主焦点、皮肤、留白、入场、停留、退场。文案必须拆成独立重点；例如将“注册地·付款方式”挤进一条标签，导致信息项混淆，不是可用的匹配。模板如需人物分层、素材、源视频关联或额外准备，读其 PRESET 与原生 API 完成准备后才报效果应用；没有人物前景不能把普通前置大字冒充身后大字。不可用则报告技术缺口并比较其他实际候选。

数值对比先确定观众要比较的两个数与单位，再审主次层级。若重点是37与52的差异，把两句话塞进两条相同小胶囊不构成有效数值强化：数字应成为主视觉，标签与单位退为辅助，在真实画幅下看得清且可直接比较。分贝使用dB；不得用线性柱高、面积、百分比或响度倍数暗示未经支持的关系。个人读数的约值与测量边界保留。现有原生模板无法给出足够收益时明确记录缺口，不能因为技术可运行就判美术通过。用户要求先看关键帧时，仅交静态候选及可编辑源，不自动制作动画或替换用户已导入的版本。

素材配合模板时仍逐句核对肯定/否定对象：说“依赖语音输入”不能用纯键盘输入画面作默认替代；说“就在嘴边”必须在实际候选中看清嘴、拾音头与距离。背景大字只重复结论，不能代替这种空间关系的实物证据。依据 `docs/real-footage-contract.md` 记录实际源窗和逐句语义验收。

## 可核对记录

新 request.templateReviewVersion=1 要求 package-contract.json 的 templateReview：

```json
{
  "version": 1,
  "sections": [{
    "sectionId": "与sections稳定id对应",
    "opportunities": ["concept", "conclusion"],
    "decision": "apply",
    "reason": "本段具体采用或留白理由",
    "candidates": [{
      "presetId": "现用真实模板id",
      "decision": "selected",
      "reason": "表达适配或排除理由",
      "visualBenefit": "主体、层级、运动、人物关系等具体画面收益"
    }]
  }]
}
```

sections按序覆盖全部语义段，不重复不遗漏。opportunities可为空；无机会可candidates=[]并具体解释真人留白。decision为apply/keep_presenter/blocked；candidate.decision为selected/rejected/blocked。apply选择须与本段templateMatch一致。可比较多个候选，不虚报已选择、不把技术阻塞当语义不适合。旧未标记请求历史兼容，不改旧产物。

只用原生模板/props/CAS；不改组件或新增动作。既有手调/锁定/删除/忽略保留；修订已被用户指出不足的自动实例，先冻结旧版、保留可恢复记录，避免新旧重叠污染预览。已应用后在当前工程播放新增与修改的全部模板区间，看真实动态与人物合成，检查文字不提前揭示后文；只抽帧则记sampled_only。最终报告列模板中文名、ID、对应口播、具体画面收益、实际实例与观看范围；不能只报模板数量、源码验证或“高级感”。

动画先行文档与完整总结分阶段交付；本次模板复审不把原生参数或模板时间塞进Claude任务，也不等待Claude回传。完整package其余七项职责继续执行；显式单项范围才跳过。
