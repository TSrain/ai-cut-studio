# Motion Studio 手动整理轨道

时间轴工具栏的「整理轨道」按钮位于悬停预览（眼睛）左侧。点击立即整理、自动保存，整个动作只占一次撤销；没有可整理内容时不创建撤销记录。

- 按元素类型合并：原生动画、视频、图片、主视频同步小窗分别整理，音频仅与音频合并。素材分屏/堆叠按各自组件类型整理。
- 时间区间不重叠可共轨，首尾相接允许；重叠片段保留分轨。不能改变与其他同时出现元素的叠加顺序，存在顺序冲突也保留分轨。
- 可移动单个片段，减少整体冲突造成的冗余轨道；不改变片段起点、时长、源入点、内容参数和渲染 zIndex。合并后保留目标轨名称。
- 保留锁定、禁用/静音轨；不同扩展轨道设置不合并。移除普通可编辑空轨，锁定/禁用或包含未知行为设置的空轨保留。
- 主视频、字幕、镜头变化、制作计划等专用数据不参与整理。音频音量、淡入淡出、分组保持不变。
- 被整理的轨道退出自动追加归属，避免后续后台自动放入新片段。该按钮用于用户主动整理已有工程；未来自动追加规则仍见 automatic-visual-tracks.md。

实现：`../studio/tools/editor/track-organization.mjs`，入口 `tools/editor/Timeline.tsx`。回归覆盖时间重叠、跨轨层级保护、单片段重排、音频、扩展设置、重复整理和撤销重做。
